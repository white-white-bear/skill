# 验收

"看起来像"和"测得出"是两件事。这一页把后者写死。

## 分层回归

| 层 | 重跑什么 | 证明什么 |
|---|---|---|
| L0 | 复用 units/ann，只 render | 排版改造没破坏成品 |
| L1 | 复用 units，重跑 annotate | 声学与音系移植正确 |
| L2 | 复用 ASR，重跑 segment + align | 分段与对齐正确 |
| L3 | 从音频重跑 asr | 分块、偏移、补空档正确 |
| L4 | 新素材端到端 | 通用性 |

`examples/steve-jobs/` 是金标准样本，`expected_metrics.json` 存聚合数字。

| 指标 | L0/L1 同输入 | L2 重跑 ASR | 新素材 |
|---|---|---|---|
| 词/句/段数 | 完全一致 | 完全一致 | — |
| 词 start MAE | 0 | ≤60 ms | — |
| 未匹配率 | 0 | ≤0.5% | ≤2% |
| 强读集合 Jaccard | ≥0.99 | ≥0.90 | 比例 10–25% |
| 弱读集合 Jaccard | ≥0.99 | ≥0.94 | 比例 15–28% |
| 连读集合 Jaccard | ≥0.98 | ≥0.90 | 比例 18–32% |

## 金标准基线（Steve Jobs，66 分钟）

```
词 11,428 · 句 564 · 段 94 · 12 章
强读 1,914 (16.7%) · 弱读 2,421 (21.2%) · 连读 2,812 (24.6%)
失爆 361 (3.2%) · 吞音 1,627 (14.2%) · 浊化 1,016 (8.9%)
H/M/L = 3,119 / 5,519 / 2,790 · 说话人基线 132.0 Hz
PDF 100 页
```

### 为什么失爆没有固定区间

失爆的机会数取决于句子长短。连续旁白里大约 3% 的词会触发，一句一停的
跟读材料里能到 6–7%——两者都是对的。用固定区间判，换一种素材就误报
（实测踩过一次：把正确的 6.4% 判成超标）。

所以失爆改查**规则执行得一致不一致**：把"词尾塞音 + 后面接辅音或句末"
的位置数出来当机会数，看标注覆盖了多少，要求 ≥95%。规则是确定性的，
漏标说明音素序列或分句出了问题。这个检查跨语料都成立。

## 怎么跑

```bash
ipa qa job.json --pdf out/<slug>.pdf     # 退出码 14 = 不达标
```

`qa` 在没有金标准时自动切到"比例健康"模式：检查六项比例是否落在区间内，
而不是和某个具体数字比。新素材走这条路。

## 新素材全流程验收

以 68 分钟、只有音频的素材为例：

1. `duration` 与 ffprobe 结果差 <0.5 秒
2. 两路 wav 时长差 <0.1 秒
3. 词速率 2.0–3.2 词/秒（明显偏低 = ASR 漏词；偏高 = 重复转写）
4. >3 秒的空档全部尝试过补转，补回来的低置信词（prob<0.4）已丢弃
5. 章节 8–14 个、不重叠、每章 3–12 分钟
6. 平均句长 10–25 词，无 >60 词的句子
7. **未解析词 0**
8. 六项比例全部落在上表区间
9. PDF 无缺字、无空白章节、每章有标题和统计
10. 随机抽 10 个词回听，核对音标和重读标记

## 最容易"像但空心"的四处

1. **章节文案模板化** — 标题对，问题是套话。防线：meta lint
2. **加标点时顺手改了词** — 音标与音频错位且看不出来。防线：只在纯文本上改，
   改词必须重跑 align
3. **照搬原素材的声学阈值** — 换个人嗓音，强读比例会跑到 35% 或 8%。防线：qa 比例带
4. **词典静默回落** — 未解析词读成 `/ˈʌn/`。防线：硬闸门
