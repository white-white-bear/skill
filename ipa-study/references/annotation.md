# 标注：哪些是测出来的，哪些是推出来的

这一页是产品的可信度底线。成品首页必须把这条分界线写清楚。

| 标注 | 来源 | 依据 |
|---|---|---|
| 音标 | **词典** | cmudict + 专名词典，按实际读法（数字、缩写、所有格单独处理） |
| 音节音高（半音） | **实测** | Praat 基频，逐音节中位数，减去句内中位 |
| H / M / L | **实测** | 同上，±2.2 半音分界 |
| 语调走向 ↗↘→ | **实测** | 重读音节基频曲线的斜率，±3.5 半音/秒 |
| 强读（红色） | **实测 + 加权判定** | 句内时长、峰值响度、基频顶点的 z 分加权 |
| 弱读 + 元音变化 | **规则** | 闭类词表 + 强读/弱读形对照 |
| 连读 | **规则 + 实测间隔** | 音素相接类型 + 词间隔 <0.06 秒 |
| 失爆 / 吞音 / 浊化 | **规则** | 音素序列上的位置与上下文 |
| 音节内配时 | **实测优先，否则插值** | 浊音段；数量对不上时按音素数摊 |

## 测量口径

- Praat 基频：75–400 Hz，步长 10 ms。
- 说话人基线：整段浊音帧的中位基频。**不是**每章各算一次——
  换章不换人。
- 半音：`12 × log2(f0 / 基线)`。正数比基线高，负数为低。
- 词级 H/M/L：相对**本句**中位，不是全书中位。句子之间的语调本来就有起伏，
  用全书中位会把整句偏低的内容全打成 L。

## 强读怎么判

```
score = 0.50 × z(整词时长) + 0.30 × z(峰值响度) + 0.20 × z(基频顶点)
      + 0.18 × (句内位置)
score > 0.62 → 强读
```

几个必须保住的设计：

- **时长用整词，不用重读音节。** 否则 `outsider` 这种多音节词会因为重读音节
  短而被系统性压低。
- **位置项只是微调。** 英语调核倾向在句末，但 0.18 的权重压不过明显的
  时长/响度证据。
- **闭类词（the / of / to / and…）永远不是强读。**
- **每个句子至少一个强读。** 短句的 z 分会整体被压平，这时按英语默认规律取
  句末最后一个实词，除非别处时长明显更长（>1.8 倍）。
- **插值词不参与判定。** `asr = null` 的词时间是借来的，测出的音高不是证据。

## 音系规则

### 弱读

`WEAK_ARP` 表里 45 个闭类词，各给强读形和弱读形。非重读时替换成弱读形，
**替换后音节结构变了，必须重新切分**——否则数字读法（`nineteen sixty-one`）
的断词位置会错位。

比较强弱读形时要去掉重音符号，否则 `/ˈhɪz/` 和 `/hɪz/` 会被误判成"元音变化"。

### 失爆 / 吞音 / 浊化

判定必须用**音素下标**，不能用字符串匹配。一个词里可能有两个 /t/，
按字符串匹配会把它们一起标掉。

- 词尾塞音后接辅音或位于停顿前 → 不除阻 `t̚`
- 词尾 /t/ /d/ 后接辅音 → 整段消失 `(t)`
- 词内 /t/ /d/ 在浊音（元音、/r/、/l/）后、非重读元音前 → 闪音 `ɾ`
- 跨词：`…Vt` + 元音开头的下一个词 → 闪音

注意 `/n/`、`/m/` 后面更常见的是直接删掉 /t/，不按浊化处理。

### 连读

只标真正的连读：辅音接元音、元音接元音、同音辅音合并。间隔 <0.06 秒才标。

## 音节配时

优先用浊音段（Praat 判定的有声区间）。段数和音节数对不上时：

- 段数多于音节数 → 取最长的几个；
- 段数少于音节数 → 按音素数比例摊分。

`annotate` 会报出每章"摊分比例"。**整章都在摊（>40%）说明声学对齐出了问题**，
正常情况下应该在 25–30%（英语里本来就有大量清音）。

## 校准

`0.62`、`±2.2`、`0.06` 这几个值是给一个语速偏慢、音域偏窄的说话人调的。

换素材后先看 `qa` 报的强读比例：

| 比例 | 判断 |
|---|---|
| 10–25% | 正常 |
| <8% | 阈值太高或基频追踪失败 |
| >35% | 阈值太低，红色会失去意义 |

偏了就改 `annotate.accent_threshold`，或者设
`calibration: "target_ratio"` + `target_accent_ratio: 0.175`，按前几章自动校准。
**不要**为了"看起来像原版"去硬套原阈值——那是把一个人的嗓音参数当成通用规律。
