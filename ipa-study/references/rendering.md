# 排版

## 图层

一个英文词占五层，从下往上：

```
        H ↗        ← 强读等级 + 语调走向（24.5pt）
   +3  -1  +2      ← 音节相对音高，半音（17pt）
    ˈdʒɑːbz        ← 音标（10pt）
     Jobs          ← 英文（基线）
       ʌ→ə         ← 弱读元音变化（-8pt）
```

行高 36pt。英文列宽取「英文宽度」和「音标宽度」的较大者 + 5.6pt。

音标比英文宽太多时（`1976` → `ˈnaɪntiːn sevənti sɪks`）按比例压小字号，
下限 5.6pt——否则一个数字会撑开整行的列宽。

## 中英混排

按字符类别切换字体：CJK 区（U+2E80 以上）用中文字体，其余用 IPA 字体。
所有宽度计算都走同一条路径，所以混排文字的居中/右对齐是准的。

## 颜色

| 用途 | 默认 | 含义 |
|---|---|---|
| `accent_color` | `#c62828` 红 | 强读 |
| `weak_color` | `#1f5fa8` 蓝 | 弱读 |
| `link_color` | `#0f8b8d` 青 | 连读弧线 |
| `lost_color` | `#8d6e63` 棕 | 失爆/吞音/浊化的附加符号 |

四类标记互不重叠，一眼能分清。改颜色只改 `render.theme`。

## 字体

`fonts.py` 按这个顺序找：

1. `render.theme.ipa_font` / `cjk_font`
2. 环境变量 `IPA_FONT` / `CJK_FONT`
3. 平台默认：Windows `l_10646.ttf` + `msyh.ttc`；macOS Arial Unicode + PingFang；
   Linux DejaVu + Noto Sans CJK
4. 包内 `assets/fonts/`

**渲染前校验必需码位**：`ɑæʌɔɛɜɪiʊuəɚ θðʃʒŋɾ ːˈˌ ↗↘→` 和组合符 `̚`。
缺一个就直接报错，不允许渲染成方框。

找不到中文字体时，界面文字自动降级成英文（`zh.json` → `en.json`），不崩。

## 功能开关

`render.features`：

- `cover` 封面
- `map` 全书地图（需要 `render.content.map_rows`）
- `pitch_page` 音高查询表
- `legend` 符号表
- `summary` 段落小结
- `chapter_questions` 每章回忆问题

形态和开关是两件事：`sections` 形态通常关掉 `map` 和 `chapter_questions`。

## 示例词必须从当前素材里挑

音高表的"本书里的例子"列、符号表里那条 IPA 样例，都从当前数据里按
「重读 + 多音节 + 有音高曲线」自动挑。

**不要照抄上一本书的 "Wozniak"**——这是空心化最典型的形态：版式一模一样，
但你翻到音高表，看到的是别人书里的词。

## 先出样张

```bash
ipa render job.json --chapters 1 --out sample.pdf
```

样张走完整封面 + 符号表 + 音高表 + 一章正文的流程，和全书一致。
确认版式后再渲染全书——版式返工比换素材贵得多。

## 已知的版面行为

- 段落之间用灰底小框做小结（弱读/连读/失爆/吞音/浊化的计数 + 最多两类实例）。
- 句与句之间额外留 13pt，弱读标记才不会和下一句的英文粘连。
- 连读弧线优先画在两个英文词之间的空白里，那里没有字形遮挡；画不下才退到
  音标行。
